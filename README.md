**The World in a Day — Tuesday, 17 November 2026.** One 1024×1024 dark
editorial poster (v2) that sums up the day's world news: a huge masthead
date, one large hero illustration for the day's biggest story, and five
cover-line stories beneath it — all flat vector art (see `image.html`),
each with a bold headline and a one-line summary:

- **Ukraine Cripples Crimea Bridge** *(hero)* — Kyiv's strike partly collapses the Kerch Bridge; Russia answers on Kyiv's Dnipro bridges.
- **US Bombs Iran Base, Tankers Burn** — jets hit Iran's Qeshm missile site; a burning gas tanker is evacuated off Oman.
- **Chip Rout Rocks Wall Street** — AI selloff deepens; Nvidia's first earnings since CEO Huang's shock exit loom.
- **US Loses Measles-Free Status** — elimination status ends after 26 years — Mexico and Bolivia too; US cases top 5,400.
- **Knesset Votes Out Netanyahu Ally** — Eisenkot-bloc speaker Kahana wins 66–52, replacing Netanyahu's man Ohana.
- **Trump Lands in Shenzhen** — leaders gather for APEC; first US–China–Russia summit set for Thursday.

V2 replaced v1's cream newspaper grid with this dark poster treatment and
sharpened three stories with fuller same-day reporting; the audit is in
`NOTES.md`.

Every story was verified against reporting dated 17 November 2026; the
research, sources and the stories deliberately left off are in `NOTES.md`.
The program itself is a small copier: it delivers the finished `entry.png`
to the output directory unchanged.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
