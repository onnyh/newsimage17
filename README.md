**The World in a Day — Tuesday, 17 November 2026.** One 1024×1024 front page
that sums up the day's world news in six illustrated panels, each drawn as
flat vector art (see `image.html`) with a bold headline and a one-line
summary:

- **Ukraine Cripples Crimea Bridge** — Kyiv's strike partly collapses the Kerch Bridge.
- **Tankers Hit Mines in Hormuz** — another tanker burns in the strait as the US–Iran war widens.
- **Chip Rout Rocks Global Markets** — selloff deepens on US export curbs; Nvidia reports after its CEO's shock exit.
- **US Loses Measles-Free Status** — elimination status ends after 26 years; cases top 5,400, a 40-year high.
- **Israel Votes Out Netanyahu Ally** — the Knesset elects Eisenkot-bloc speaker Kahana 66–52.
- **APEC Opens in Shenzhen** — Quad leaders meet; Trump arrives before Thursday's first US–China–Russia summit.

Every story was verified against reporting dated 17 November 2026; the
research, sources and the stories deliberately left off are in `NOTES.md`.
The program itself is a small copier: it delivers the finished `entry.png`
to the output directory unchanged.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
